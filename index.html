About This Repository

This repository tracks learning journals and exercise artifacts across two parallel CareerFoundry pathways: Full-Stack Web Developer (frontend foundations & application development) and Python for Web Developers (backend foundations with Django). Each journal captures goals, takeaways, pitfalls, and next steps in a concise, beginner-friendly format.

Full-Stack Web Developer — Highlights (selected)

  • Frontend fundamentals: semantic HTML5, CSS3 (Flexbox/Grid), responsive design, and accessibility.
  • JavaScript (ES6+): modules, async flow (promises/async-await), DOM APIs, and data fetching.
  • Framework practice: React/Angular exercises (components, routing, state), plus build tooling (Node.js, npm).
  • Version control & workflows: Git/GitHub, branching strategies, code reviews, and documentation standards.
  • Portfolio & case studies: iterative UX thinking and deployment basics.

Python for Web Developers — Achievement 1: Foundations (Exercises 1.1–1.7)

  • Core Python: data types, control flow, functions, modules, and error handling.
  • OOP essentials and practical file/database I/O.
  • Environment setup (venv, pip) and VS Code workflow.
  • CLI “Recipe” app: incremental design, refactors, and testing essentials.

Python for Web Developers — Achievement 2: Web Development & Django

  • Exercise 2.1: MVT vs MVC, Django benefits/constraints; install & verify in a clean venv; scenarios for when to use Django.
  • Exercise 2.2: Create project structure, run migrations, start dev server, create superuser, (optional) first app.
